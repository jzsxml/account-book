# 产品模块与 MVP 路线图

## 七大模块对照

| 模块 | 当前实现 | 说明 |
|------|----------|------|
| **1. 记账** | ✅ 收入/支出、分类、日期、备注、附件 | 缺：转账、多账户必选、保存 Toast |
| **2. 分类与账户** | ✅ 自定义分类（商务图标） | ✅ 默认多账户；缺：二级分类、转账 |
| **3. 统计报表** | ✅ 周/月/年、折线/饼图、筛选 | ✅ 收支结余总览；缺：柱状对比图 |
| **4. 预算控制** | ✅ 月度总预算 + 使用率 | 缺：分类预算、超支推送 |
| **5. 账单汇总** | ✅ 年总览 + 12 月明细入口 | 与流水筛选联动 |
| **6. 用户与安全** | ✅ 注册验证、改密、头像、登录审计 | 缺：导出/备份 |
| **7. 系统设置** | ✅ 主题、工具、昵称 | 缺：导入导出、提醒 |

导航：**首页 · 统计 · ＋ · 明细 · 我的**（中央「+」半屏快速记账，先分类后金额）。

## 周 / 月 / 年怎么看

- **统计页**：周期切换 + **收入 / 支出 / 结余** 总览、趋势折线、分类饼图与占比条。
- **账单汇总**：选定年份 → 12 个月卡片（收入、支出、结余）→ 点击进入当月流水。

## MVP 阶段

**已完成（本轮）**：账单汇总、统计总览、账户、月度预算、记一笔成功反馈。

**阶段 2（已完成）**：`GET /api/stats?month_report=1` 月报；`/stats/report` 本月报告（排行、TOP 支出、预算）；`period=day` 今日总览。

**阶段 3（已完成）**：`GET /api/stats?habits=1` 连续天数/本周笔数/最佳记录；7 天与 30 天里程碑徽章（首页 + 我的）；首次解锁 Toast。

**后续**：转账、定期账单、分类预算、柱状图、数据导出、多账本 UI。
